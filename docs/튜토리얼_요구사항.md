# 📋 MahaGarage 앱 튜토리얼 기능 요구사항 정의서

본 문서는 MahaGarage(차계부 앱)의 **대화형 인터랙티브 튜토리얼(Interactive App Tour)** 기능에 대한 요구사항을 심플하고 명확하게 정리한 문서입니다.

---

## 1. 진입 및 트리거 (Entry Points)

* **최초 실행 시 진입**:
  * 앱 설치 후 최초 실행 시 팝업 다이얼로그 노출
  * 문구: *"튜토리얼을 보시겠습니까?"*
  * 선택지: `[튜토리얼 시작]` / `[건너뛰기]`
* **설정 메뉴 내 재실행**:
  * 설정(Settings) 화면에 `[튜토리얼 다시 보기]` 항목 상시 제공
  * 완료 여부와 무관하게 언제든 다시 시작 가능
* **상태 저장**:
  * 튜토리얼 완료 또는 건너뛰기 시 `is_tutorial_completed` 플래그 로컬 저장

---

## 2. 연출 및 UX 핵심 원칙 (Core UX Principles)

* **실제 화면 기반 시뮬레이션 (In-Situ Tour)**:
  * 별도의 동떨어진 안내 화면이나 팝업 페이지만 띄우는 방식 금지
  * **실제 앱 화면의 버튼 및 입력 필드 위치** 위에서 포인터(커서/터치)가 이동하고 반응해야 함
* **인터랙티브 애니메이션**:
  * 마우스 커서(또는 터치 포인터)가 대상 버튼으로 부드럽게 이동
  * 타겟 요소에 클릭 애니메이션(리플 효과) 및 포커스 하이라이트(스포트라이트) 적용
* **스텝별 네비게이션 제어**:
  * 하단 툴팁/컨트롤러에 `[이전]`, `[다음 / 확인]`, `[건너뛰기/종료]` 버튼 제공
  * 사용자가 `[확인]` 또는 `[다음]`을 누르면 실제 해당 메뉴/페이지로 이동하며 다음 단계 진행
* **데이터 무결성 보장**:
  * 튜토리얼 중 가상 입력 및 클릭 시 실제 DB에 불필요한 데이터가 영구 저장되지 않도록 시뮬레이션 모드로 동작

## 3. 단계별 튜토리얼 시연 시나리오 (5 Steps)

### Step 1. 차량 등록
* **화면**: 메인 대시보드 / 차량 등록 화면
* **시연 내용**:
  1. 차량 추가 버튼 포커싱 & 클릭
  2. **카탈로그에서 모델 선택** 방식 시연
  3. **번호판 조회를 통한 자동 제원 등록** 방식 시연

### Step 2. 계기판 ODO 및 주행거리 입력
* **화면**: 차량 상세 / 대시보드
* **시연 내용**:
  1. 계기판 `ODO` 버튼 포커싱 & 클릭
  2. 현재 누적 적산거리(km) 입력 다이얼로그 호출 및 갱신 시연

### Step 3. 주유 기록 및 연비 계산 (카메라 OCR)
* **화면**: 주유/정비 등록 화면
* **시연 내용**:
  1. 주유 기록 추가 버튼 클릭
  2. **카메라 OCR 버튼** 클릭 및 영수증 자동 스캔/인식 연출
  3. 주유량·금액 자동 입력 및 누적 연비 실시간 계산 로직 안내

### Step 4. 사고·고장 긴급출동 신고
* **화면**: 메인 대시보드 상단/플로팅 액션
* **시연 내용**:
  1. `사고/고장 긴급출동` 버튼 하이라이트
  2. 보험사 긴급출동 전화 연결 및 사고 접수 기능 위치/사용법 안내

### Step 5. 카히스토리 및 정비 이력 관리
* **화면**: 차량 관리 / 카히스토리 탭
* **시연 내용**:
  1. 정비 이력 및 카히스토리 메뉴 포커싱
  2. 소모품 교체 주기(D-Day, 남은 거리) 및 과거 정비 내역 확인 방법 안내
  3. `[튜토리얼 완료]` 버튼 노출 및 정상 종료

---

## 4. 조작 및 제어 기능 (Controls & Options)

| 구분 | 요구사항 |
| :--- | :--- |
| **스텝 진행** | 단계 인디케이터 표시 (예: `Step 1 / 5`) |
| **중도 종료** | 우측 상단 `[X]` 버튼 또는 `[건너뛰기]` 클릭 시 즉시 튜토리얼 종료 |
| **화면 이동** | 각 스텝 전환 시 해당 기능 화면으로 라우팅 자동 전환 |
| **반응형 대응** | 기기 해상도/화면 비율에 맞춰 타겟 버튼 좌표 동적 계산 |
