마하개러지 1.0.4 (versionCode 5)

수정 사항
1. 타이어 스왑 표시 위치를 바꿔도 실제 장착 대상은 현재와 반대 계절로 유지합니다.
   저장 중 중복 클릭을 막고, 저장 성공 후에만 창을 닫습니다.
   저장 오류는 창 안에 표시하며 앱 종료로 이어지지 않도록 처리합니다.
   대시보드에서도 입력한 주행거리/보관장소/잔여홈/비용/메모를 모두 저장합니다.
   최신 DB 차량 상태를 기준으로 처리해 오래된 화면의 중복 저장을 차단합니다.
   처음 전환하는 계절의 타이어 세트가 없으면 정보 미등록 상태로 네 바퀴 기록을 만듭니다.
2. 벤츠 A/B/C/E/S/G 클래스 영문/한글/하이픈/대소문자/이니셜 검색을 지원합니다.
   예: E클래스, e-class, E, 벤츠 E, G바겐, 지바겐, GLC.
   모델 검색 정보를 캐시하고 여러 검색어를 조합할 수 있습니다.
3. 시작 시 기본 정비 카탈로그 적용성을 갱신하고 기존 차량의 누락 규칙을 보충합니다.
   HEV/PHEV 가솔린/디젤은 엔진오일/흡기필터/냉각수/미션오일을 유지합니다.
   기존 정비 이력, 직접 설정한 주기, 사용자가 비활성화한 항목은 보존합니다.
   이미 순수 전기차로 잘못 등록된 차량은 차량 수정에서 실제 동력계를 선택해야 합니다.
4. 카탈로그 선택 버튼은 MASK1 원본 nature-sprite 마스크의 23개 프레임을 사용합니다.
   중앙에서 먹물처럼 색이 빠지고 다시 채워지는 반복 효과입니다.
   마스크 리소스를 앱에 포함하여 인터넷 연결 없이 동작합니다.

검증
- Android 앱 APK 및 Android 화면/DB 회귀 테스트 APK 빌드 성공.
- JVM 단위/회귀 테스트 전체 113개 통과.
- 추가 검증: 벤츠 클래스 별칭, 하이브리드 4종 부품/점검도, 스왑 왕복 주행거리/입력 보존.
- Android 화면/DB 테스트는 컴파일 완료. 가상 기기가 연결되지 않아 실행하지 못했습니다.
- 실제 휴대폰에서의 동작 및 애니메이션 최종 육안 확인은 아직 수행하지 못했습니다.

빌드
Android Studio에서 프로젝트를 열고 Android SDK 35 및 Java 17 이상을 설정하세요.
각 환경의 SDK 경로는 Android Studio가 local.properties에 생성하게 하세요.
gradlew.bat :app:assembleDebug
gradlew.bat :app:testDebugUnitTest
연결한 테스트 기기가 있으면: gradlew.bat :app:connectedDebugAndroidTest

동봉 APK는 디버그 서명된 테스트용입니다.
기존 설치 앱과 서명이 다르면 덮어쓰기가 되지 않습니다. 기존 서명으로 다시 빌드하세요.
기존 정비 기록을 유지하려면 앱을 삭제하기 전에 백업 내보내기를 사용하세요.

MASK1 리소스 출처 및 이용 조건은 THIRD_PARTY_NOTICES.txt를 참조하세요.
